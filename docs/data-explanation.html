数据说明

关于风险分数

我们的风险分数是基于 VAERS（疫苗不良事件报告系统）数据计算得出的综合性评估指标，范围从 0 到 10。

计算方法

基础分数 = 死亡率 × 2.0 + 严重反应率 × 0.5

然后根据用户个人因素进行调整：
  • 65岁以上：+1.5
  • 50-64岁：+1.0
  • 糖尿病：+0.8
  • 心脏病：+0.8
  • 免疫缺陷：+1.0
  • 曾感染COVID：-0.3

风险等级

  • 低风险 分数 < 4.0：不良反应报告相对较少
  • 中等风险 分数 4.0-7.0：有一定比例的严重反应
  • 高风险 分数 ≥ 7.0：严重反应报告比例较高

关于症状统计

症状数据来自接种者的不良事件报告，展示接种后不同症状的出现频率。

严重程度分类

  • ⚠️ 严重症状：可能导致住院、残疾或死亡的症状，如呼吸困难、胸痛、血栓等
  • 🟡 常见症状：大多数接种者会经历的轻度至中度症状，如头痛、疲劳、发热等
  • 🟢 轻微症状：较少出现或症状轻微，通常无需特殊处理

时间分布

症状出现时间分布显示接种后不同时间段内症状报告的数量，帮助了解症状出现的高峰期。

数据来源

VAERS（Vaccine Adverse Event Reporting System）
美国疫苗不良事件报告系统，由 CDC 和 FDA 运营。

数据网址：https://vaers.hhs.gov/data/datasets.html

重要说明

⚠️ 免责声明

  • VAERS 是被动报告系统，存在漏报和报告偏差
  • 相关不等于因果 - 报告的事件不一定由疫苗引起
  • 本平台数据仅供参考，不能替代医疗建议
  • 如有健康疑虑，请咨询专业医疗人员

如何理解数据

报告多 ≠ 危险

高报告量可能表示：

  • 该批次接种人数多
  • 公众关注度高
  • 医疗机构报告意识强

建议

  • 结合风险分数和症状列表综合判断
  • 关注严重症状的出现率，而非绝对数量
  • 如有基础疾病，请咨询医生
